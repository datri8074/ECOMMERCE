# 🛒 E-Commerce Website

A simple **E-Commerce Website** built using **PHP, MySQL, HTML, CSS, and JavaScript**. It allows users to browse products, manage their cart, and place orders, while admins can manage products through a dedicated dashboard.

## ✨ Features

- User Registration & Login
- Product Browsing
- Shopping Cart
- Checkout
- Admin Login
- Add, Edit & Delete Products

## 🛠️ Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 Setup

1. Clone the repository.
2. Move it to the `htdocs` folder (XAMPP).
3. Create a MySQL database.
4. Import the SQL file.
5. Update `includes/db.php` with your database credentials.
6. Run the project at:
   ```
   http://localhost/ecommerce
   ```
